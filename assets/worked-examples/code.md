# 原创输出样本：从记录到唯一 ID

用途：局部代码知识、设计选择与执行追踪。全部输入为合成，`keep` 是已确定的教学条件。

```python
rows = [
    {"id": "v1", "keep": True},
    {"id": "v1", "keep": False},
    {"id": "v2", "keep": True},
]
kept = [row for row in rows if row["keep"]]
ids = {row["id"] for row in kept}
```

> 我们要得到两种结果：保留的完整记录，以及这些记录支持的唯一 ID。因此这里分别使用列表和集合。第二步的去重不能代替第一步的逐条判断。
>
> 先把列表推导式展开：

```python
kept = []
for row in rows:
    if row["keep"]:
        kept.append(row)
```

> 第一条被加入；第二条虽然也是 v1，但条件为 False，不加入；第三条被加入。随后从两条保留记录取 ID，得到集合中的 v1 和 v2。集合不承诺你可以依赖的输出排列顺序；需要排序时必须明确排序规则。

反思：如果之后按这个 ID 集合回到原始 `rows` 中取所有匹配记录，第二条会不会回来？这说明记录资格与 ID 是否入选有什么区别？

应用：让学习者把输入改为两条均合格且 ID 相同的记录，分别预测 `kept` 和 `ids` 的长度，解释为什么不能随意对完整来源记录去重。
