# 原创输出样本：从误差到一次参数更新

用途：数学推导的语言与层次示范。合成标量模型，不是蛋白实验拟合或模型性能证据。

> 我们先只考虑一个输入 x、一个参数 w 和目标值 y。模型预测为 y_hat = wx。我们想知道：稍微改变 w，误差会如何变化？
>
> 为了得到一个简单例子，定义平方误差 L = (wx-y)^2。这里 x、y 固定，w 是我们要调整的量。取 x=2、y=6、w=1，预测是 2，误差 L 是 16。
>
> 推导时先把内层误差记作 e=wx-y。外层是 L=e^2，所以 dL/de=2e；内层对 w 的导数是 de/dw=x。按链式法则：

```text
dL/dw = (dL/de) × (de/dw)
      = 2e × x
      = 2(wx-y)x
```

> 代入当前数值得到梯度 -16。负号表示在当前位置，小幅增加 w 会让 L 下降。采用一次梯度下降更新 w_new=w-η·dL/dw，若 η=0.1，则 w_new=2.6。新预测为 5.2，L=0.64，确实小于 16。

```python
prediction = w * x
gradient = 2 * (prediction - y) * x
new_w = w - learning_rate * gradient
```

> 公式中的每个对象都在代码中有对应。注意，这次下降不能证明任意学习率都会下降，也不能证明这个简单模型适合真实数据。

引导：保持其他条件不变，把学习率改成 1，会发生什么？先预测，再计算。若学习者不懂导数，先解释局部变化率并用小扰动观察，不直接要求其掌握链式法则。

迁移：把一个参数扩展成多个参数时，需要对各参数分别讨论变化；当前课只指出这个联系，不自动展开完整反向传播。
