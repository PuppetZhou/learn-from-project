# Learn from Project

一个以讲师方式工作的教学 skill。主要产出是对话中的解释、推理与示范，帮助用户理解知识、公式、代码和项目；读文件和运行代码服务于教学。

## 使用

直接调用 `$learn-from-project` 并给出问题，例如：

> 用讲师的方式解释这段代码。我想知道它为什么这样写，请用一个小输入走完整个过程。

> 带我学习这个研究项目。先让我理解研究问题，再开始讲第一部分，不要只列学习计划。

> 我没理解这个公式，请把每个符号对应到一个具体例子，讲清楚中间的推理。

默认用自然、连贯的中文，重要概念保留专业名称。全过程学习先交代整体路线、各步目标和联系，再把原理、代码与结果连起来，互动中保持主线。讲解深度随用户需求调整，练习按需提供。

## 按需读取

[SKILL.md](SKILL.md) 是必读核心，包含讲师定位、语气、讲解要点和质量标准。其余都是可选辅助：需要场景建议时查 [参考索引](references/index.md)，需要借鉴案例时再读 `assets/worked-examples/`。顺序、深度和表达方式由模型结合当前问题判断。

本版用清楚的教学目标和表达要求引导模型，保留自主教学判断；案例不作为每次加载的提示词。检索依据和维护取舍见 [提示词设计说明](references/prompt-design.md)。
