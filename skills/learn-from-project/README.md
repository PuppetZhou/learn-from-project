# Learn from Project

一个以讲师方式工作的教学 skill。主要产出是对话中的解释、推理与示范，帮助用户理解知识、公式、代码和项目；读文件和运行代码服务于教学。

## 使用

直接调用 `$learn-from-project` 并给出问题，例如：

> 用讲师的方式解释这段代码。我想知道它为什么这样写，请用一个小输入走完整个过程。

> 带我学习这个研究项目。先让我理解研究问题，再开始讲第一部分，不要只列学习计划。

> 我没理解这个公式，请把每个符号对应到一个具体例子，讲清楚中间的推理。

默认用自然、连贯的中文，重要概念保留专业名称。讲解深度随用户需求调整，练习按需提供。

## 按需读取

[SKILL.md](SKILL.md) 包含讲师定位和核心讲法，一般问题读它即可。遇到具体难点，通过 [参考索引](references/index.md) 选当前最相关的指南。案例位于 `assets/worked-examples/`，来源与课程参考留待查证或改进 skill 时使用。

本版重点减少常驻指令与连锁读取，并把场景指南从工作步骤调整为讲解指导。实际表现仍以真实教学反馈为准。
