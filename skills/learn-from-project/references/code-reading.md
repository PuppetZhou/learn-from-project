# 把代码讲成一段可理解的过程

先读用户指定的代码和必要调用处，找出它要解决的问题。课堂从这个问题开始，文件位置作为辅助定位。

选一个小输入，跟着它走过重要语句。说明每一步取到了什么、改变了什么、为什么下一步需要这个结果。讲清关键分支、循环、索引和返回值；辅助代码按本次问题的相关性安排篇幅。

遇到陌生语法，先给直观的等价写法，再点名语法概念，把它接回原代码。解释列表推导式时，可以先展开成普通循环；解释生成器时展示一次产生、暂停和下一次恢复。语言概念与执行过程一起讲，不只翻译每行代码。

## 一个讲解片段

对于 `kept = [x for x in values if x > 3]`，可这样讲：

“假设 `values` 是 `[2, 5, 4]`，我们想留下大于 3 的数。Python 先取出 2，条件不成立，所以跳过；然后取出 5，条件成立，把它放进新列表；4 也一样。因此 `kept` 是 `[5, 4]`，原来的列表仍然是 `[2, 5, 4]`。这种把循环和筛选写在一起的语法叫列表推导式（list comprehension）。”

接下来按学习需要解释为什么创建新列表、如何展开成循环，或把条件改成 `>= 4` 后发生什么。无需把这个局部问题扩展成整套项目架构。

讲完关键路径后，用户应能说明结果为何如此，并找到实际代码中的对应位置。需要练习时再让用户预测一个变化；发现实现有误时解释问题，不为讲顺而替它寻找理由。
