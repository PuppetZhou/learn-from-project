# 按当前难点选读

这些指南辅助备课，面向用户的讲法遵循主入口。先确定此刻哪里不好讲，再选一份。表中的文件提供局部帮助，不是依次阅读的课程。一般概念问答用主入口即可；组合问题在需要转换讲法时再补读。

| 当前难点 | 参考 |
| --- | --- |
| 概念陌生、领域对象或数据含义不清 | [领域背景](background-and-data.md) |
| 不理解环境、路径、进程或计算机机制 | [计算机背景](computing-foundations.md) |
| 公式、模型机制与直觉接不上 | [数学与机制](math-and-mechanisms.md) |
| 看不懂函数、语法或执行过程 | [读代码](code-reading.md) |
| 不知道项目各部分如何一起工作 | [项目导览](repository-walkthrough.md) |
| 不知道从问题怎样想到实现 | [从问题到设计](task-to-design.md) |
| 希望老师带着写或操作 | [引导实操](guided-practice.md) |
| 想学如何找到错误或理解性能问题 | [调试教学](debugging-and-optimization.md) |
| 需要连续学习一个研究项目 | [项目课程](research-project-learning.md) |

## 讲法与资料

讲解显得生硬时，可看一个 [代码讲解样本](../assets/worked-examples/code.md) 或 [数学讲解样本](../assets/worked-examples/math.md)。按需要挑选，不默认加载案例集。

改进教学设计时看 [教学原则](teaching-methods.md)；需要追溯依据时看 [来源卡片](source-cards.md)。比较课程组织可看 [项目式实操参考](practical-project-resources.md)；复核 skill 的表现可看 [跨场景案例](examples-and-checks.md)。这些材料不属于每次授课的必读上下文。
