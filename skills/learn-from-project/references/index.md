# 按当前难点选读

本索引及其链接全部为可选资料。角色、语气和讲解要点已在主入口中给全；只有需要具体帮助时才选读相关部分。各指南提供可调整的建议，不规定统一讲解顺序或输出栏目。

| 当前难点 | 参考 |
| --- | --- |
| 复杂概念不好理解，需要调整语言、例子或解释深度 | [表达与分层讲解](explanation.md) |
| 需要澄清学习目标、讨论路线或保存跨轮进度 | [学习讨论与进度](learning-dialogue.md) |
| 概念陌生、领域对象或数据含义不清 | [领域背景](background-and-data.md) |

## 讲法与资料

需要借鉴表达时，可看 [代码讲解样本](../assets/worked-examples/code.md) 或 [数学讲解样本](../assets/worked-examples/math.md)。案例不属于必读内容；可自行构造更适合当前问题的例子，不必模仿样本的结构或措辞。

改进教学设计时看 [教学原则](teaching-methods.md)；需要追溯依据时看 [来源卡片](source-cards.md)。比较课程组织可看 [项目式实操参考](practical-project-resources.md)；复核 skill 的表现可看 [跨场景案例](examples-and-checks.md)。这些材料不属于每次授课的必读上下文。

本 skill 的提示词设计依据见 [提示词设计说明](prompt-design.md)，仅供维护和比较不同 agent 表现时查阅。
