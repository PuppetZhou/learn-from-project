# 教学代码：简洁、可读、对应学习重点

仅在编写或改写示范代码时使用。先判断代码是本次学习对象，还是帮助理解理论的演示。

学代码时，把关键语法、数据结构和执行过程写得可追踪；演示理论时，让符号、变量和运算一一对应，将篇幅留给原理。只用库调用会隐藏当前要学的机制时，展开必要的核心运算；与当前重点无关的操作可使用现成工具。

优先清楚的变量名、直接的控制流程和短而完整的计算过程。简洁指减少无关复杂度，不是压缩行数；难读的一行表达式可以展开，重复或有独立含义的步骤再提取函数。注释解释理由、维度或易混点。

依赖和抽象以当前示范所需为准。配置系统、通用框架、日志与异常处理，仅在它们影响本次理解或运行时加入。简化实现仍保留正确的计算和必要条件。

让读者看得到输入、关键中间结果和输出。代码较长时按学习阶段分段，并说明如何衔接；承诺可运行 demo 时给足运行所需内容。讲原理的伪代码或片段说明用途即可，不能冒充完整实现。

阅读现有项目时可另给简化的等价片段帮助理解，说明与原代码的对应；不为讲解而自动重构原项目。
