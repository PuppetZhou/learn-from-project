# 计算机背景补课

用于计算思想、算法、数据结构、系统机制或操作技能成为当前理解缺口时。范围开放，按任务确定所需知识，不把本文件中的主题当完整课程或边界。与领域背景分开判断：理解领域问题不等于熟悉计算方法。

操作问题可以先描述可观察动作，再定义对象与关系；算法问题可以先讨论目标、规模和策略，再追踪小输入；概念问题可直接比较定义与反例。例如运行 Python 文件：shell 解释命令并启动解释器，解释器执行代码，进程读取磁盘输入、占用内存、写出结果。按实际操作解释，不讲无关操作系统历史。

下表是选择教学内容的例子，可以替换或扩展，不是每次必讲清单。

| 当前障碍 | 可考虑的知识 | 可用检查 |
| --- | --- | --- |
| 不知道如何选算法 | 问题结构、正确性、时间/空间成本及适用前提 | 对比小例子，并解释规模变化后的取舍 |
| 不理解 Linux 管道或重定向 | shell、标准输入输出、组合与退出状态 | 预测一个无破坏性命令的输出流向 |
| 不理解 Git 操作 | 工作区、暂存、提交、分支与远程关系 | 区分本地保存与远程发布 |
| 路径找不到 | 当前目录、相对/绝对路径、文件与目录 | 预测同一相对路径在不同目录指向哪里 |
| 模块未安装 | 解释器、环境、包、版本；安装与运行须对应 | 核对运行的解释器，而非盲目重装 |
| 脚本为何占内存 | 磁盘文件与运行中对象，列表与逐批读取 | 说明分批读取何时才能限制内存 |
| 压缩文件读不懂 | 文本、字节、编码、压缩、归档各层职责 | 判断解压与解析哪个先失败 |
| 怎么快速查大文件 | 顺序扫描与索引，索引依赖文件版本/坐标 | 解释没有索引时为何不能假设随机定位 |
| 多进程是否更快 | 任务、CPU/I/O、独立内存与共享瓶颈 | 列出需要测量的一个瓶颈 |

保留真实机制：进程不是脚本文件，磁盘空间不是内存，安装了包不代表每个解释器都能导入。类比之后立即回到具体对象，不把“缓存”“索引”等解释成万能加速器。

可参考 [原创讲解样本](../assets/worked-examples/computing.md)。若只需一个概念，讲完即可；若是项目操作中的缺口，补完后明确回到原任务。
