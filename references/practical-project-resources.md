# 项目式实操参考

这些外部案例供导师按当前任务查阅，用于观察如何连接研究问题、方法依据、代码和结果解释；不作为固定课表，也不替代现有教学原则。案例保留在参考资料层，不要求每次教学加载。

## Single-cell Best Practices

- 来源：Lukas Heumos、Anna Schaar 与 Single-cell Best Practices consortium；[网站](https://www.sc-best-practices.org/)。
- 查阅日期：2026-11-08。
- 本轮阅读范围：网站介绍、Quality Control 和 Differential gene expression 章节的网页内容。未运行 notebook，未验证环境或复现分析结果。
- 定位：面向单细胞分析的项目式实践教材，按分析环节组织背景、方法选择、数据、代码与结果。适合参考如何组织跨步骤实操；不是通用机器学习教材。

### 从案例中借鉴什么

以下是本 skill 对所读材料的归纳，不是作者发布的通用教学规范，也不增加必须逐项执行的要求：

- 让一个研究问题连接各阶段，解释当前输出为何是后续分析的输入。
- 在需要作选择的地方解释方法依据与取舍，而非先堆积全部理论或直接给工具命令。
- 将简短代码与对应的数据状态、输出和解释放在一起，使学习者能追踪处理产生的变化。
- 根据检查结果和下游问题回到前一步，展示研究过程中的调整与判断。

使用时选择与当前困难相关的一段即可；迁移的是组织与解释方式，新的教学数据、方法和顺序仍由当前项目决定。需要实际复现时，从原章节的数据与 notebook 入口取得材料，再核对版本、资源及授权；不因引用此教程自动下载或运行整套分析。

### 适用边界与来源性质

网站明确不系统教授基础编程或基础生物学，因此导师仍需补足当前任务的先修缺口。单细胞方法、阈值、统计单位和数据表示不能直接迁移为其他项目的科学规则。

网站说明其建议尽可能依赖外部 benchmark 与综述，缺少外部验证时也会依赖实践经验。教学组织值得参考，不代表各项科学建议已经适用于当前数据；实际选型仍应查原始依据。网站也明确区分书籍内容审阅与正式同行评审，不能把配套综述的发表等同于每一版在线代码均获验证。

该资源持续更新。未来用于实操时记录实际采用的章节、数据和环境版本；本记录仅代表上述阅读范围。这里只保存链接与原创归纳，不复制原站完整教程、代码或图像。
